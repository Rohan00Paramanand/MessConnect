# Implementation Plan - Phase 4: Invitation-Based Onboarding for College Admins

This plan implements **Option 2: Invitation-Based Onboarding for College Admins**, replacing the public self-registration flow with secure, token-based email invitations generated by the Super Admin.

## User Review Required

> [!IMPORTANT]
> - **No Public Admin Registration**: We will remove the `college_admin` option from the public registration form (`Signup.jsx`).
> - **Secure Invitation Links**: The Super Admin will generate invitations for college admins from their dashboard. An invitation link with a cryptographically secure token (e.g. `${CLIENT_URL}/accept-invite?token=abc...`) will be emailed to the admin.
> - **Simplified Registration Flow**: Invited college admins do not need to perform OTP phone/email verification when signing up via the invitation link, as email possession is verified by clicking the single-use token link sent to their inbox.

## Proposed Changes

### Backend Changes

#### [NEW] [invitation.model.js](file:///wsl.localhost/Ubuntu-22.04/home/anshgupta/Projects/MERN/MessConnect/server/src/models/invitation.model.js)
- Define `Invitation` schema:
  - `email`: String, required, unique.
  - `collegeId`: ObjectId, ref: 'College', required.
  - `token`: String, required, unique.
  - `expiresAt`: Date, required.
  - `isAccepted`: Boolean, default: false.

#### [MODIFY] [superadmin.controller.js](file:///wsl.localhost/Ubuntu-22.04/home/anshgupta/Projects/MERN/MessConnect/server/src/controllers/superadmin.controller.js)
- Add `inviteAdmin`:
  - Validates email and college slug/ID.
  - Checks if user with this email already exists (returns 400).
  - Deletes any existing pending invitations for this email.
  - Generates a cryptographically secure token.
  - Saves the `Invitation` record (expiry: 7 days).
  - Sends an invitation email with a link like `${CLIENT_URL}/accept-invite?token=${token}`.
- Add `getInvitations`:
  - Returns a list of all sent invitations, populated with college details.

#### [MODIFY] [superadmin.routes.js](file:///wsl.localhost/Ubuntu-22.04/home/anshgupta/Projects/MERN/MessConnect/server/src/routes/superadmin.routes.js)
- Register routes:
  - `POST /api/superadmin/admins/invite` -> `inviteAdmin`
  - `GET /api/superadmin/admins/invitations` -> `getInvitations`
  - *(Note: We can deprecate the old `/admins/pending` and `/admins/:id/approve` endpoints as self-registration is no longer allowed)*

#### [MODIFY] [auth.controller.js](file:///wsl.localhost/Ubuntu-22.04/home/anshgupta/Projects/MERN/MessConnect/server/src/controllers/auth.controller.js)
- Add `getInvitationByToken`:
  - Verifies token validity, expiry, and that it has not been accepted.
  - Returns `{ email, collegeName }`.
- Add `acceptInvitation`:
  - Validates `token`, `name`, `password`, `phoneNumber`.
  - Checks for duplicate emails or phone numbers.
  - Creates the user as `role: "college_admin"` with `isVerified: true`, `isApprovedByAdmin: true`, and the mapped `collegeId`.
  - Marks the invitation as `isAccepted: true`.

#### [MODIFY] [auth.routes.js](file:///wsl.localhost/Ubuntu-22.04/home/anshgupta/Projects/MERN/MessConnect/server/src/routes/auth.routes.js)
- Register public routes:
  - `GET /api/auth/invitation/:token` -> `getInvitationByToken`
  - `POST /api/auth/accept-invitation` -> `acceptInvitation`

## Verification Plan

### Automated/Manual Verification
1. **Remove self-registration**: Verify that visiting the `/signup` page no longer shows "College Admin" as a registration option.
2. **Send Invitation**:
   - Log in as Super Admin (`admin@messconnect.com`).
   - On the dashboard, fill out the "Invite College Admin" form with an email (e.g. `collegedean@test.com`) and choose an active college.
   - Click "Send Invitation" and verify it is successfully added to the invitation list.
   - Check CLI console to verify email mock logs the invitation link correctly.
3. **Accept Invitation**:
   - Copy the link generated in the server logs (e.g., `/accept-invite?token=...`).
   - Visit the link in a browser.
   - Verify the email and college name are correctly pre-filled and read-only.
   - Fill in details (Name, Phone Number, Password) and click "Register".
   - Verify it successfully creates the user account and redirects to `/login`.
4. **Log in as Invited Admin**:
   - Try to log in with the new admin email and password.
   - Verify they are logged in directly and redirected to `/dashboard/college_admin` without pending verification errors.
5. **Check Invitation Table**:
   - Log back in as Super Admin and verify the status of the invitation has changed to "Accepted".
